# - numpy MUST stay at 1.26.4 -- newer numpy 2.x breaks the compiled dlib wheel.
# - opencv-python MUST stay below version 5.x -- the 5.x release removed/changed
#   cv2.CascadeClassifier in a way that breaks this project.
# - dlib is not listed here because it doesn't have a pip-installable wheel for
#   very new Python versions (e.g. 3.13/3.14). Install it manually from a
#   precompiled .whl matching your Python version, e.g.:
#   https://github.com/z-mahmud22/Dlib_Windows_Python3.x
#   Then run: pip install dlib-19.24.1-cp311-cp311-win_amd64.whl (adjust filename)
#   BEFORE running: pip install -r requirements.txt
